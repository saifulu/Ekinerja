# Aplikasi Ekinerja

Aplikasi ini dipisah menjadi dua bagian utama (Frontend dan Backend):

1. `/backend` - API menggunakan Laravel 12.
   - Cara menjalankan: Buka terminal, masuk ke folder `backend`, lalu jalankan `php artisan serve`.
2. `/frontend` - UI menggunakan Next.js.
   - Cara menjalankan: Buka terminal, masuk ke folder `frontend`, lalu jalankan `npm run dev`.
